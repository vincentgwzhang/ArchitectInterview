# 02. 缓存、搜索、消息队列与流量削峰

## 读取

CloudFront 缓存图片/公开页面，Redis Cache 商品热点，OpenSearch 提供全文与 Facet。Catalog DB 是 Source，CDC/Event 更新 Search/Cache，接受明确 Lag。

## 峰值

API 限流、Admission Control、Auto Scaling；SQS/Kafka 缓冲订单后续处理。Queue 不能替代同步库存/支付确认，但可移出通知、履约和 Analytics。

## Cache 风险

TTL Jitter、Single Flight 防击穿，Negative Cache 防穿透，Redis 故障时保护 DB。价格/库存 Cache 只作展示，Checkout 再验证。

## 搜索

Index 分片、Alias Blue/Green、Query Complexity 和降级到 Category/热门商品。搜索故障不应阻断直接商品页与 Checkout。

## 监控

Cache Hit、Origin/DB QPS、Search P99/Error、Queue Age、Hot Key/Partition 和 Reindex 状态。

## 总结

Cache、Search 和 Queue 各自承担读取、检索和时间解耦；必须明确 Source of Truth、Staleness 和故障降级。
