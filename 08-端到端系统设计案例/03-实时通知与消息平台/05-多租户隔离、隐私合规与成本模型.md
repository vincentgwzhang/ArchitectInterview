# 05. 多租户隔离、隐私合规与成本模型

## 隔离

可信 Identity 派生 Tenant；API/DB/Queue/Cache/Metric 全链路带 Tenant Scope。大 Tenant 使用独立 Partition/Quota，防 Noisy Neighbor。

## 权限

Tenant Admin 管 Template/Preference/API Key，但不能访问其他 Tenant。Webhook Secret 每 Tenant 独立轮换，日志和 Export 受授权。

## 隐私

最小化 Message Content，敏感 Payload 可只传 Reference 并在 App 内认证查看。Retention、Deletion、Consent、Quiet Hours 和 Data Residency 明确。

## Provider

记录 Subprocessor、Region、Delivery Log 与 DPA。不要在 URL/短信包含长期 Secret 或完整敏感数据。

## 成本

单位成本 = Stream/Queue + Gateway Connection + Provider Fee + Storage/Log + Egress。按 Tenant/Channel 分摊，设置 Budget 和昂贵渠道审批/Quota。

## 总结

多租户通知平台必须同时隔离数据、容量和成本。隐私与供应商边界是架构核心，不是后续配置。
