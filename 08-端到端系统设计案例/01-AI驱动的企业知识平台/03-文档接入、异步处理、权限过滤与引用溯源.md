# 03. 文档接入、异步处理、权限过滤与引用溯源

## Pipeline

Source Connector 增量采集 → S3 Raw → SQS/Step Functions → Parse/OCR → Chunk → Metadata/ACL → Embed → Keyword/Vector Index。

每步 Idempotent，以 Source ID + Version/Checksum 去重；失败进入 DLQ，保存状态和重试。大型文档异步处理并展示 Ingestion Status。

## 权限

同步 Source ACL、Group 和 Tenant。权限变更优先级高于内容更新，撤权需快速传播。Query 使用可信 Identity Filter；Citation 打开时再次授权。

## Lineage

Chunk 保存 Document、Section/Page、Offset、Version、Parser/Chunker/Embedding Version。答案引用可回到确切原文。

## 删除与版本

Source 删除产生 Tombstone，清理 Keyword/Vector/Cache。Blue/Green Index 完成后原子切换，避免半索引状态。

## 监控

Ingestion Lag、Parse/Embedding Failure、ACL Missing、Index Drift、Deleted Content Leakage 和 Citation Broken Link。

## 总结

知识平台的可信度取决于接入、权限和 Lineage。模型只是最后一步，数据管道错误会直接变成错误或泄露。
