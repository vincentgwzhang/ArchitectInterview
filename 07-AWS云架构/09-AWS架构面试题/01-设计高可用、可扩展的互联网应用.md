# 01. 设计高可用、可扩展的互联网应用

## 需求

澄清用户地域、Peak RPS、读写比、SLO、数据一致性、RTO/RPO、安全与预算。

## 参考架构

```text
Route53 -> CloudFront + WAF -> ALB
-> ECS/EKS/EC2 Auto Scaling across 3 AZ
-> ElastiCache
-> Aurora/RDS Multi-AZ + Read Replica
-> SQS/EventBridge for async work
S3 for object/static content
```

## 可扩展

服务无状态；CDN/Cache 吸收读；Queue 削峰；数据库 Index/Replica，达到证据阈值再 Partition。Auto Scaling 同时保护 DB Connection 与下游 Quota。

## 可用性

跨 AZ、Health/Graceful、Timeout/Circuit/Rate Limit、Degraded Mode。Backup/PITR 与跨 Region DR 根据 RTO/RPO。

## 安全

Multi-account、Private Subnet、SG、IAM Role、KMS/Secrets、WAF/Shield、CloudTrail/GuardDuty。Backend 执行 Resource Authorization。

## 运营与成本

CloudWatch/OTel、SLO Burn Rate、Canary Deployment、IaC/GitOps。CDN、Graviton、Savings Plans、Spot（异步）和 Unit Cost。

## 面试亮点

从需求和容量推导，不要一次画满所有 AWS 服务；明确 Bottleneck、Failure 和演进阶段。
