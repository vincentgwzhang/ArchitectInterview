# 01. S3 存储类型、生命周期、版本控制与复制

## 存储类型

Standard 适合频繁访问；Intelligent-Tiering 自动分层；Standard-IA/One Zone-IA 适合较少访问；Glacier 系列适合归档，取回时间和费用不同。选择考虑 Access Frequency、最短存储期、Retrieval 和 Availability。

## Key 与性能

S3 是 Object Store，不是文件系统。Object Key、Metadata、Tag 和 Prefix 支持组织与 Lifecycle。大对象使用 Multipart Upload；应用使用 Pre-signed URL 避免中转。

## Versioning

保留历史版本，保护误覆盖/删除；删除会产生 Delete Marker。Versioning 增加存储，需 Lifecycle 清理旧版本。结合 MFA Delete/Object Lock（按需求）防篡改。

## Lifecycle

按时间/Tag 转换 Storage Class、删除旧版本和 Abort Incomplete Multipart。归档前评估 Retrieval 费用与合规 Retention。

## Replication

SRR/CRR 可跨 Bucket/Region 复制，需要 Versioning、IAM 和监控。复制是异步的，RPO 不是零；既有 Object 需 Batch Replication。

## 安全

Block Public Access、Bucket Policy、SSE-KMS、VPC Endpoint、Access Log/CloudTrail Data Event。避免 ACL，优先 Bucket Owner Enforced。

## 总结

S3 设计围绕生命周期、Durability、访问模式与权限。Version/Replication 不是 Backup 的全部，还需恢复与删除治理。
