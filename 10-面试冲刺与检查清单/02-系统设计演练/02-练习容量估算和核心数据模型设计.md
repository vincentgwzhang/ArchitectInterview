# 02. 练习容量估算和核心数据模型设计

## 估算

快速计算 Average/Peak QPS、并发、日增长、年存储、带宽和 Cache。使用数量级并说出假设。

```text
QPS = daily operations / 86,400
Concurrency ≈ RPS × latency seconds
Storage = records × size × retention × replication
```

## 映射架构

读多提示 CDN/Cache；大 Blob 提示 Object Storage；峰值写提示 Queue；单 Key 热点提示分区问题。数字必须改变设计讨论。

## Data Model

列出 Entity、Key、Invariant、Access Pattern、Index、Ownership 和 Retention。不要一开始追求完整 ERD。

## 练习

每题 5 分钟估算，并在最后说“最大不确定因素是什么、如何通过 Load Test/生产数据验证”。

## 总结

容量估算用于验证数量级，数据模型用于保护业务语义。精确小数不如清晰假设和架构结论。
