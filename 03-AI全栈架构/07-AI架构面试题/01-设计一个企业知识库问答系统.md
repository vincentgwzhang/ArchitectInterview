# 01. 设计一个企业知识库问答系统

## 需求

澄清 Source、用户/租户、权限、Language、Freshness、Citation、SLA、数据敏感度和回答风险。核心 NFR 是“不能跨权限泄露”。

## 高层架构

```text
Sources -> Connector -> Parse/Chunk -> Metadata/ACL
        -> Embedding -> Vector + Keyword Index

React -> Java AI Gateway -> Auth/Policy
      -> Query Rewrite -> Hybrid Retrieval + ACL
      -> Rerank -> LLM -> Citation Validation -> Stream
```

## Ingestion

增量同步、Checksum、版本、Tombstone 删除。保留 Title、Section、Page、Source URL、ACL、Effective Date、Parser/Embedding Version。

## Query

1. 从可信 Identity 获取 Tenant/User Group。
2. Rewrite Query，但保留精确 Term。
3. Hybrid Search + ACL Pre-filter。
4. Rerank、Dedup、Context Budget。
5. 要求基于证据回答或 Abstain。
6. 验证 Citation 并流式返回。

## 安全

Document-level ACL、Cross-tenant Test、Prompt Injection Isolation、PII Redaction、Provider Policy、Audit。Citation Link 也必须再次授权。

## Reliability

Vector Search 故障可回退 Keyword Search；LLM 故障时展示 Search Result，而不是编造答案。限流、Circuit Breaker、Cancel 和 Provider Fallback。

## 评估

Retrieval Recall@K、Answer Correctness、Groundedness、Citation、ACL Leakage、P95 Latency、Cost/Answer 和 User Task Completion。

## 演进

从单一 Source/Language 开始，先建立 Eval。再加入 Rerank、Query Decomposition、Memory 和更多 Source，而不是一开始建设全自主 Agent。

## 面试亮点

重点讨论 ACL、删除传播、Citation Correctness、分层 Eval 和证据不足时拒答。
