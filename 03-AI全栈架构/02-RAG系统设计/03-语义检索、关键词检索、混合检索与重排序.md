# 03. 语义检索、关键词检索、混合检索与重排序

## Semantic Search

Embedding 能找到表达不同但语义相近的内容，适合自然语言问题与概念匹配。弱点包括精确 ID、缩写、罕见术语、数字和新词。

## Keyword Search

BM25 等方法擅长精确 Term、产品编号、Error Code 和专有名词，也具有成熟 Filter 与 Explain 能力。对同义表达和自然语言意图较弱。

## Hybrid Search

同时获取 Vector 与 Keyword Candidate，再融合 Ranking：

- Weighted Score。
- Reciprocal Rank Fusion（RRF）。
- Learned Fusion。

不同系统的 Raw Score 不可直接比较，RRF 常是稳健起点。

## Metadata Filter

先根据 Tenant、ACL、Language、Region、Product、Effective Date 限制 Candidate。Pre-filter 更安全且减少搜索范围；某些 ANN 实现中复杂 Filter 可能影响 Recall 与 Latency，需要测试。

## Reranking

第一阶段 Retriever 用低成本方式召回几十到几百个 Candidate；Cross-encoder 或 LLM Reranker 对 Query-Document Pair 精细评分，选 Top N 进入 Prompt。

Rerank 提升 Precision，但增加 Latency 与 Cost。可对简单 Query 跳过，或只 Rerank Top 20。

## Retrieval Pipeline

```text
Query -> ACL/Intent -> Rewrite
      -> Vector + BM25 Retrieval
      -> Fusion -> Rerank -> Diversity/Dedup
      -> Context Selection
```

## Diversity

Top Result 可能来自同一段的重复 Chunk。使用 Parent Dedup、MMR、Source Cap 和 Section Diversity，让 Context 覆盖多个独立证据。

## 评估

- Recall@K：相关证据是否被召回。
- Precision@K：Top K 中有多少相关。
- MRR/nDCG：相关结果排序是否靠前。
- Zero-result Rate。
- Retrieval Latency。

先评 Retrieval，再评 Generation。答案错误可能是“没有取到证据”，也可能是“模型没有正确使用证据”。

## 总结

生产 RAG 通常不是纯 Vector Search。Hybrid Retrieval、Metadata Filter、Rerank 与 Diversity 共同提高精确词和语义问题的覆盖。
